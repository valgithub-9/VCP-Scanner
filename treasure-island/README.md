# 🏝️ 3D 尋寶島（入門版）

給國小三到六年級的 3D 程式設計入門範例：先有一座可以探索的島，再把島變成尋寶遊戲。

## 怎麼開始

1. 用 Chrome 或 Edge 打開 `index.html`（直接雙擊即可，需要連上網路來載入 Three.js）。
2. 按「開始尋寶！」，跟著發光的光柱找寶箱。

| 操作 | 電腦 | 手機／平板 |
|---|---|---|
| 移動 | `W A S D` 或方向鍵 | 左半邊畫面拖曳 |
| 跳 | 空白鍵 | 右下角「跳」按鈕 |
| 轉動視角 | 拖曳滑鼠 | 右半邊畫面拖曳 |
| 拉近／拉遠 | 滑鼠滾輪 | — |
| 俯瞰全島 | `V` | — |

想換一座島，可以按「換一座島」，或在網址後面加上 `?seed=1234`（任何數字都可以）。同一個數字，永遠是同一座島，方便全班一起比賽。

## 孩子可以改什麼

打開 `index.html`，最上面的 `設定` 就是「島的遙控器」：

```js
const 設定 = {
  島的種子: 2026,     // 換數字 = 換一座島
  島的大小: 70,
  山的數量: 3,
  山的高度: 14,       // 夠高的山頂會下雪
  樹的數量: 120,
  房子的數量: 6,
  寶箱的數量: 8,
  海的顏色: '#2f8fd8',
  數學闖關: false,    // true：答對數學題才能打開寶箱
  數學難度: 1,        // 1 加減、2 九九乘法、3 混合
  時間限制: 0,        // 例如 120 = 兩分鐘挑戰
  ...
};
```

改完存檔，重新整理網頁就能看到結果。

## 建議的課程進度

| 年級 | 做什麼 | 學到的概念 |
|---|---|---|
| 三年級 | 改 `設定` 的數字，探索自己的島 | 參數、3D 空間、觀察因果 |
| 四年級 | 打開數學闖關、限時挑戰，自己出題 | 條件判斷、變數 |
| 五年級 | 照著 Skill 的配方加金幣、障礙物、火山 | 座標、距離、碰撞偵測 |
| 六年級 | 雙人競速、AI 機器人對手、把全班的島拼成群島 | 函式重複使用、簡單 AI、陣列 |

## 造島 Skill

造島的方法整理在 [`.claude/skills/build-island/SKILL.md`](../.claude/skills/build-island/SKILL.md)，內容包括：

- 開始前要問孩子的三個問題
- 造島的八個步驟，每一步都附上「跟孩子這樣說」
- 必須遵守的規則（單一檔案、中文命名、設定集中在最上面）
- 加新東西的配方：火山、金幣、障礙物、雙人競速、AI 機器人、群島
- 完成後的檢查清單

在這個專案裡使用 Claude Code 時，直接說「幫我在島上加一座火山」，Claude 就會照著這份 Skill 來修改島。
