# 造島 Skill：先做出一座島，再讓島變成遊戲

這份 Skill 記錄了「怎麼造一座 3D 島」的方法。下次再造島、或幫島加新東西時，照著這裡的步驟做，就不用從頭想。

範本在 `treasure-island/index.html`。**每次都從範本開始改，不要從零開始寫。**

---

## 一、開始前，先問孩子三個問題

一次只問一個，用孩子聽得懂的話：

1. **你的島長什麼樣子？**（大島還是小島？有幾座山？要不要下雪？）
2. **島上有什麼？**（樹、房子、火山、城堡、恐龍……都可以）
3. **在島上要做什麼？**（只是逛逛？找寶箱？答題闖關？跟同學比賽？）

把答案對應到 `設定` 裡的數字。範本沒有的東西，就到下面的「加新東西的配方」找做法。

---

## 二、造島的八個步驟

範本裡的程式已經照這個順序排好，每一段都有編號註解。跟孩子解釋時，一次只講一步。

| 步驟 | 範本裡的段落 | 跟孩子這樣說 |
|---|---|---|
| 1. 種子 | `島的種子`、`做隨機器` | 「同一個數字，永遠長出同一座島。換數字就換一座島。」 |
| 2. 舞台 | `場景`、`鏡頭`、`太陽` | 「先搭好舞台、架好攝影機、打開太陽。」 |
| 3. 地形 | `地面高度(x, z)` | 「島中間高、旁邊低，再疊上幾座山。」 |
| 4. 上色 | `地面顏色` | 「低的地方是沙灘，高的是草地、岩石，最高的山頂有雪。」 |
| 5. 海 | `海浪動起來` | 「海是一大片會上下動的平面。」 |
| 6. 找空地 | `找空地` | 「放東西前先檢查：太陡不行、在海裡不行、跟別的東西太近也不行。」 |
| 7. 擺東西 | `蓋一間房子`、`放一個寶箱`、`種一棵樹` | 「每樣東西都是用方塊、圓錐、圓柱拼起來的積木。」 |
| 8. 角色和規則 | `探險家`、`更新玩家`、`更新寶箱` | 「角色會走、會跳、碰到寶箱就得分。」 |

---

## 三、一定要遵守的規則

- **只用一個 `index.html` 檔案。** Three.js 用網路上的 CDN 載入（`three@0.160.0`），雙擊就能打開，不需要安裝任何東西。
- **所有孩子會想改的數字，都放在最上面的 `設定` 裡**，並用中文命名、在旁邊寫建議範圍。新功能如果有開關，也加進 `設定`（例如 `火山: true`）。
- **變數和函式用中文命名，註解寫給國小生看。** 句子要短，不用專有名詞；非用不可時，先用生活裡的例子解釋。
- **新的物件一律先用 `找空地()` 找位置**，放好後記得加進 `已放的東西`；角色不能穿過的東西，也要加進 `障礙物`。
- **形狀只用簡單幾何體**（Box、Cone、Cylinder、Sphere、Icosahedron），保持積木風格。孩子一看就知道「這是一個方塊加一個圓錐」。
- **每做完一步，就打開網頁看一次。** 不要一口氣改很多東西。
- **不要重做別人的遊戲**（名字、角色、畫面）。這座島是孩子自己的作品。

## 四、加新東西的配方

每個配方都寫成「放在哪裡 → 怎麼做 → 要教的概念」。

### 🌋 火山
- **放在哪裡：** 第 3 步 `山們` 後面，把其中一座山標記為 `是火山: true`。
- **怎麼做：** 在 `地面高度` 裡，火山中心附近把高度往下挖一個坑（`h -= 坑的深度 * Math.exp(...)`）。`地面顏色` 讓坑裡變成紅橘色；坑上方放幾個會往上飄、慢慢變淡的灰色方塊，當作煙。
- **要教的概念：** 函式可以「疊加」，也可以「挖掉」。

### 🪙 收集金幣
- **放在哪裡：** 照著 `放一個寶箱` 寫一個 `放一枚金幣`。
- **怎麼做：** 用扁扁的金色圓柱，在 `每一格()` 裡讓它旋轉；碰到就消失、分數加 1。
- **要教的概念：** 變數（分數）、距離判斷（`Math.hypot` 算兩點有多遠）。

### 🪨 會動的障礙物
- **怎麼做：** 用一顆滾來滾去的石頭（球體），位置隨時間改變：`x = 起點x + Math.sin(秒) * 5`。碰到的話，角色回到出生點。
- **要教的概念：** 座標、時間讓東西動起來、碰撞偵測。

### 🔢 數學闖關
- 範本已經內建，把 `數學闖關` 改成 `true` 就能用。`數學難度` 有 1／2／3 三種。
- **延伸：** 讓孩子自己在 `出題()` 裡加新題型，例如「□ + 5 = 12」。
- **要教的概念：** 條件判斷（答對 → 打開；答錯 → 再想想）。

### ⏱ 限時挑戰
- 把 `時間限制` 改成秒數（例如 `120`）。
- **要教的概念：** 倒數計時、比較大小（時間用完了沒？）。

### 🏃 雙人競速
- **怎麼做：** 複製一個 `探險家`，換顏色。第一位玩家用 WASD，第二位用方向鍵，各自記分數，先找到一半寶箱的人獲勝。鏡頭改成俯瞰全島（`鏡頭狀態.俯瞰 = true`）。
- **要教的概念：** 同樣的程式可以用兩次（物件／函式重複使用）。

### 🤖 AI 機器人對手
- **怎麼做：** 機器人每一格都朝最近、還沒被打開的寶箱走一小步，速度比玩家慢一點。
- **要教的概念：** 簡單的 AI 就是「看看四周 → 選一個目標 → 往那裡走」。

### 🔗 把同學的島連在一起
- 不需要真的連線。每個人把自己的 `島的種子` 和 `設定` 抄下來，老師把幾組設定放進一個陣列，用 `位移` 把每座島錯開擺在同一片海上，就成了一個群島。
- **要教的概念：** 陣列、座標平移。

## 五、完成後的檢查清單

- [ ] 打開網頁沒有出現錯誤（按 F12 看「主控台」，沒有紅字）。
- [ ] 換三個不同的 `島的種子`，每座島都長得合理：寶箱不在海裡，房子不在山頂。
- [ ] 把 `寶箱的數量`、`樹的數量` 改成很大或 0，程式不會壞掉。
- [ ] 手機打開也能玩：左邊拖曳移動，右邊拖曳轉視角，有「跳」按鈕。
- [ ] 孩子能指出自己改的是哪一行，並說出改了之後島變成什麼樣子。

---

## 六、跟孩子說話的方式

- 先讓他看到結果，再解釋原理。「你看，山變高了！是因為我們把 `山的高度` 從 14 改成 25。」
- 孩子提出新點子（「可以有火山嗎？」），先說「可以！我們一起想想看要怎麼做」，再帶他找配方。
- 出錯的時候說「我們來當偵探，找找看是哪一行出了問題」，不要直接幫他修好。
- 每次結束，請孩子用一句話說說「今天我的島多了什麼」。把這句話寫進作品的註解裡，就是他自己的造島紀錄。
